# 끝말잇기 대결

AI와 끝말잇기를 하는 웹 게임입니다. 난이도는 5단계입니다.

| 단계 | AI가 쓰는 낱말 | AI 전략 |
|---|---|---|
| 1 쉬움 | 기초 어휘 1~2등급 | 한방 단어 안 씀, 낱말 뜻 보여 줌 |
| 2 중급 | 기초 어휘 3등급까지 | 한방 단어 안 씀, 낱말 뜻 보여 줌 |
| 3 고급 | 기초 어휘 4등급까지 | 가끔 잇기 힘든 말을 냄 |
| 4 도전 | 한국어기초사전 | 한방 단어를 섞어 씀 |
| 5 끝장 | 표준국어대사전 | 늘 가장 잇기 힘든 말(한방 단어)을 노림 |

## 규칙

- 두 글자 이상 명사, 두음법칙 허용, 같은 말 다시 쓰기 금지
- 첫 단어로 한방 단어 금지 (AI도 첫 대답에서는 한방 단어를 쓰지 않음)
- 사람은 표준국어대사전 낱말에 더해 우리말샘의 방언·북한어·옛말, 고유명사도 쓸 수 있음
- AI는 방언·북한어·옛말·고유명사를 쓰지 않음
- 힌트(초성과 뜻), 기권 버튼

## 데이터 출처

- 국립국어원 표준국어대사전, 우리말샘, 한국어기초사전 (CC BY-SA 2.0 KR)
- 국립국어원 「국어 기초 어휘 선정 및 어휘 등급화 목록」(공공누리 제1유형)

`words.json`은 위 사전의 라이선스(CC BY-SA 2.0 KR)를 따릅니다.

## 데이터 다시 만들기

1. [spellcheck-ko/korean-dict-nikl](https://github.com/spellcheck-ko/korean-dict-nikl)의 `stdict/*.xml`을 `data/stdict/`에, `opendict/*.xml`을 `data/opendict/`에 넣습니다.
2. 옆 폴더 `202610 korean word`(끝말잇기 낱말 사전)에 `words.json`과 `data/krdict/*.xml`이 있어야 합니다.
3. `python scripts/build_words.py`
